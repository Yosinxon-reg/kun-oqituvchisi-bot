# @kun_oqituvchisi_bot

«Kun ustozi» guruhiga tushgan har bir ustoz uchun «Kun o'qituvchisi» tashakkurnomasini (JPG) tayyorlab,
Monitoring bo'limi rahbariga ketma-ket raqam va belgilangan izoh bilan yuboradi.
Registon filiallari — Registon emblemasi va muhri; Sergeli Turkiston — Turkiston emblemasi va muhri.

Holat (`state.enc`) shifrlangan. Token va kalit GitHub Secrets'da: `BOT_TOKEN`, `STATE_KEY`.
